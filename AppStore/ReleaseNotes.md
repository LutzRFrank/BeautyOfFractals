# App Store Release Notes

## Version 2.10.1

### macOS

- Deep quality now offers an extended manual range of up to 160,000 iterations for resolving exceptionally slow-escaping Mandelbrot structures.
- Automatic mode retains its responsive defaults; the additional range is available only when deliberately selected.

### iPhone and iPad

- Deep quality now offers an extended manual range of up to 128,000 iterations for resolving exceptionally slow-escaping Mandelbrot structures.
- Automatic mode retains its responsive defaults; the additional range is available only when deliberately selected.
